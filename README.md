# SkyWorld Stall — Owner frontend

Stall owner dashboard + portal login.

- Dashboard: `index.html`
- Sign-in: `portal/index.html`

## Setup

I-edit `config.js` → `API_BASE` = backend URL.

Backend `ALLOWED_ORIGINS` must include this site’s origin.

## Deploy

Static host (GitHub Pages, Netlify, Vercel, etc.).
